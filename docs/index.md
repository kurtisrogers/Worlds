# Welcome to Worlds

Worlds is a reader-funded publishing platform for emerging authors.

## What you can do

- **Authors**: Write in our editor, upload DOCX files, or sync from Google Sheets
- **Readers**: Discover serial fiction, unlock chapters, or subscribe (Bronze/Silver/Gold)
- **Everyone**: Support creators directly — we only take 2% for operating costs

See the project README for installation and development setup.
