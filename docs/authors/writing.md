# Writing on Worlds

## In-app editor

1. Create a story from your dashboard
2. Click **Write** or open the editor from chapter management
3. Write with autosave — changes save every 2 seconds
4. Use toolbar buttons for bold, italic, and scene breaks

## Chapter settings

From **Manage → Settings** on each chapter:

- **Publish**: Make visible to readers
- **Unlock price**: One-time purchase in cents (e.g. 299 = $2.99)
- **Tier required**: Bronze, Silver, or Gold subscription level

## Subscription tiers

Every story gets three default tiers when created:

| Tier | Default price |
|------|---------------|
| Bronze | $4.99/mo |
| Silver | $9.99/mo |
| Gold | $19.99/mo |

Customize tiers from the Django admin or future settings UI.
