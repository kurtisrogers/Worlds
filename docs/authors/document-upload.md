# Document Upload

Upload `.docx` files to import chapters automatically.

## Format

Use headings to mark chapters:

```
Chapter 1: The Beginning
First paragraph of chapter one...

Chapter 2: The Journey
Content for chapter two...
```

If no chapter headings are detected, the entire document becomes Chapter 1.

## Upload

1. **Manage → Integrations → Upload document**
2. Select your `.docx` file
3. Chapters are created or updated by number
